# Companion Memory mobile

This combined Capacitor package was split so iOS and Android can ship different
plugins, entitlements, and store listings.

- **iOS:** [`frontend/apps/ios`](../ios)
- **Android:** [`frontend/apps/android`](../android)

Shared React UI still lives in [`@ci/fe-web`](../web). Native plugins live in
[`frontend/packages/capacitor-*`](../../packages).
